# T-284 — The menu's temple name and the signed-in person's name are never cut off

**Files changed** (all inside the contract):
- `frontend/components/Sidebar.tsx` — name display only. Menu rows untouched.

## What changed

Person's name (foot of the menu): `truncate` removed. It now wraps between words, balanced (`text-balance`). "Karuna Murti Das" is 101.9px of text in a 99px column, so it shows as "Karuna" / "Murti Das". The row grows from 44px to 56px.

Temple name (column and phone bar): `whitespace-nowrap` and `overflow-hidden` removed from the class list. `fitToWidth` now:
- measures on one line and keeps it on one line only when it fits at or above a floor (18px in the column, 14px in the phone bar);
- below the floor, stops shrinking and wraps between words at the floor size;
- when it cannot measure (hidden, zero width), leaves the name to the CSS, which wraps. A failed fit costs a line, never letters;
- re-fits whenever the name's box changes width (ResizeObserver), not only on mount and on font load.

Cause of the verifier's "ISKCON South Benga": his screenshot shows the name at 28px. That is the size `fitToWidth` sets before it measures. The measurement ran against the wrong width, and nothing ever measured again. `nowrap` plus `overflow-hidden` then cut it off. I could not reproduce the wrong width in my Chrome: the old code fitted the name to 21px on every load I measured. The fix closes both halves: it re-measures on width change, and a bad measurement can no longer clip.
