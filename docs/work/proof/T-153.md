## What `/generate` answers now, found rather than assumed

`POST /api/v1/purchase-orders/generate` matches the `/{id}` pattern, which only answers GET and PUT,
so Spring raises `HttpRequestMethodNotSupportedException`. `GlobalExceptionHandler.handleWrongMethod`
answers that, like a missing path, with `RESOURCE_NOT_FOUND`: **HTTP 404, code `KMS-400030`**. The
test asserts exactly that and it passed (below). I did not open `ErrorCode.java`. The code value is
confirmed by the passing `jsonPath("$.code").value("KMS-400030")`.
