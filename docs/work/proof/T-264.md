## What was built

- **R-SL-1 and R-SL-2.** The Suggested box shows `entryQuantity(suggestedQty, unit)`, so 3000 gm reads as "3" beside "Kg". What is typed is read in the unit beside the box (`fromEntry`), so 2.5 beside Kg saves 2500 gm. The box is keyed on its amount and unit, so a reload that changes gm to Kg rebuilds the box instead of leaving a stale figure beside a new label. Nothing rounds on the client: the figure is the server's buying amount, and a typed figure is sent exactly as typed, converted to the stored unit.
- **R-SL-3.**
  - **Vendor's pack on the list:** the box counts packs ("4" beside "× Bag (25 Kg)"), with "= 100 Kg" under it. Changing the count to 5 saves 125 Kg.
  - **The ingredient's own packs (not the vendor's):** an amount box, with the packs written under it ("1 × 1 Kg + 1 × 250 gm").
  - **In the panel:** each pack size is its own editor line. The box counts packs, and whole packs are required. Save sends `packSizeId`, `packCount`, and `quantity` = count × pack size.
  - **Plain lines** go into the panel in their readable unit (3 Kg, not 3000 gm), and the PO line is written in Kg. The server accepts any unit in the same family.
- **Prices (ruling 2).** Pressing Generate reads `api.getVendor(id).supplies` first.
  - When the vendor sells this pack, the pack price is the one they quoted. Otherwise it is the list price × the pack size.
  - `expectedPrice` is sent per the line's `unit`, which is how T-260 reads it.
  - The words under the item read, for example, "List price ₹1,500 / bag · ₹60 / Kg" or "List price ₹71.20 / Kg".
  - If the vendor cannot be read, the panel opens with no price and no words. The server fills the blank price from the list price.
- **R-SL-4.**
  - The "No vendor yet" tile gains a Vendor column (a Choose vendor dropdown with the tick beside it) and the bulk bar.
  - Choosing a vendor moves the line at once, as page state.
  - **With the tick on:** for each line, `listIngredientSupplies` is read and this vendor's row is found. Then `setVendorSupply` is called with all six keys and Preferred on. An existing link keeps its list price, lead time, pack and price per pack. A packed link is sent as the vendor page sends it (pack price, per-unit price null), because the server refuses both at once (KMS-400163). Then the list reloads.
  - **If the existing row cannot be read,** nothing is written, and the error says the move is for this visit only.
  - **With the tick off,** there is no call, and the move lasts until the page is left.
  - The active vendors are read only when a line has no vendor.

## Judgement calls

1. **Choosing in the dropdown is the action** (R-SL-4: "Choosing a vendor moves the line"), with no second button. This holds for the bulk bar too. Risk: on some Windows browsers, arrowing through a closed select fires a change on each key.
2. **The dropdowns have a fixed width (176px), not the width of the longest vendor name.** Measured before the fix, one long vendor name made every dropdown 276px wide. That pushed the page sideways at 390 (scroll width 396 against 390) and the table 3px past its tile at 1280. The closed dropdown only ever reads "Choose vendor…", so nothing is cut off, and the open list shows every name in full.
3. **The Vendor column is flexible (`TD_SECOND`), and the chips no longer break inside a word.** At 1280 the column cannot fit the dropdown and tick side by side: they need about 380px, and the fixed columns already take 453 of the 884. So the tick sits under the dropdown, which is what "beside the line where they fit" allows. Before this change, the column took its width from the ingredient name, which broke onto four lines, and "shortfall" split into "short / fall". The chip fix (`whitespace-nowrap`) applies to every tile.
4. **The rate follows the unit the quantity is shown in**, as ruled. So a 250 gm pack reads "₹100 / 250 gm · ₹0.40 / gm". The vendor page (T-252) always states a per-gram price per Kg. The two screens therefore differ for small packs. That is for Rajeev.
5. **The pack word comes from the label.** "Bag (25 Kg)" gives "bag". An unnamed pack uses its size ("1 Kg"), as in "₹400 / 1 Kg".
6. The old tile sentence, "Set one on the ingredient", became "These have no preferred vendor yet. Choose a vendor for a line, or one for every ticked line."
