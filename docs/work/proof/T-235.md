## How things were measured

Local http://localhost:3000 sent my tab to /sign-in, so **none of the real pages were measured signed in.**
Instead I measured on /sign-in, which loads the same compiled stylesheet. I put a fixed-width iframe
(320/390/768/1023/1280) of /sign-in on the page and hid its content. Then I injected a copy of each
screen's markup, using the exact class strings from the source, and measured it with
getBoundingClientRect, scrollWidth, a Range around the text, and a zero-size probe for baselines.
So the results below are measured on **copies with made-up data, not the live pages**. The copies
have no sidebar at 1280.
