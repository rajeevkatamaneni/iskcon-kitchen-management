## The fill script

What it does: reads the temple's stock items with no `kn` glossary row (same SQL as
`StockNameFillService`), turns each into its read-aloud form with a line-for-line port of
`IngredientNames.readable`, asks Claude for all of them in one call, checks every answer is plain
Kannada script and numbered correctly, then inserts with `ON CONFLICT DO NOTHING`,
`machine_provider='claude'`, `machine_translated_at=now()`. It never updates a row.

It runs SQL as `kms_app` (not superuser, no BYPASSRLS) through `docker exec … psql`, with
`SET LOCAL app.tenant_id` inside the transaction, so RLS decides what it sees and writes. `--dry-run`
asks Claude and writes nothing.

The Claude call, built by the script:

```
env -i PATH=/usr/bin:/bin:/usr/sbin:/sbin:<dir of claude> HOME=… USER=… LANG=en_US.UTF-8 \
  (cwd: a fresh empty mktemp dir, removed afterwards)
claude -p --setting-sources "" --disable-slash-commands --tools "" --strict-mcp-config \
  --model opus --no-session-persistence --system-prompt "<kitchen namer>" \
  --output-format json --json-schema '{"names":[{"n":int,"kannada":string}]}' "<instruction + numbered list>"
```

`--json-schema` is supported by CLI 2.1.289; the answer comes back in `structured_output`. The
instruction is in the script: the cook's everyday word in Kannada script, not a literal translation; no
English transliteration unless cooks really say it; preparation words translated naturally or dropped
when the store item is the same thing; plain name form, no brackets or case endings.

Readable port checked against the Java's own documented cases:

```
'Water, hot' -> 'Hot water'
'Banana, ripe, mashed' -> 'Ripe mashed banana'
'Tamarind, for the water' -> 'Tamarind, for the water'
'Wood apple (bela), ripe' -> 'Ripe wood apple (bela)'
'Ghee,' -> 'Ghee,'
'Rice, broken' -> 'Broken rice'
'Ghee, for finishing' -> 'Ghee, for finishing'
'Amul, unsalted' -> 'Unsalted amul'
```

### Doubtful, and why

- **Raw rice → ಅಕ್ಕಿ**, the same as Rice. Loses the raw/boiled distinction; ಹಸಿ ಅಕ್ಕಿ (Google's) may be better.
- **Coriander → ಕೊತ್ತಂಬರಿ ಸೊಪ್ಪು** (the leaves). If the store item "Coriander" is the seed or powder, this is wrong.
- **Turmeric powder → ಅರಿಶಿನ**, same as Turmeric; cooks usually say ಅರಿಶಿನ ಪುಡಿ.
- **Axone → ಹುದುಗಿಸಿದ ಸೋಯಾಬೀನ್** ("fermented soybean"): a description, not a word anyone uses. No Kannada name exists.
- **Perilla seed → ಪೆರಿಲ್ಲಾ ಬೀಜ**: English sound in Kannada script. Same reason.
- **Saffron or kesari colour → ಕೇಸರಿ ಅಥವಾ ಕೇಸರಿ ಬಣ್ಣ**: reads "kesari or kesari colour". The store item itself is ambiguous.
- **Eno / soda → ಈನೋ ಅಥವಾ ಸೋಡಾ ಪುಡಿ**, **Ash gourd or cucumber, cubed**: long because the store item names two things.
- **Coconut, diced small → ಸಣ್ಣ ತೆಂಗಿನಕಾಯಿ ಚೂರು** can read as "a small coconut's pieces"; ತೆಂಗಿನಕಾಯಿ ಚೂರು alone may be cleaner.
- **Cashew, halved → ಅರ್ಧ ಗೋಡಂಬಿ** ("half cashew"); cooks may say ಗೋಡಂಬಿ ಚೂರು or just ಗೋಡಂಬಿ.
