# E10-T8 — `claude -p` against the local `/mcp`: 20 questions (10 EN, 10 KN), tool choice 20/20

Built in the main checkout on `agentic-mvp`. Nothing committed. No backend code changed.

**Result: 20/20 picked the correct tool, and 20/20 answers quote figures that match the tool result.**
A control run of the 10 Kannada questions, with the Kannada word list taken out of the system
prompt, also scored 10/10.

## Files changed (all new, all under `tools/assistant-dev/` or this proof)

- `tools/assistant-dev/mint-token.py`: dev-only agent-token minter, Python stdlib. It uses the same
  claims as `AgentTokenService.mint`: `sub tenant conv scope iat exp`, HS256, `typ: JWT`, scopes sorted
  and space-separated, exp = iat + 300 s. It uses the same base64 key, and refuses a key under 256 bits
  or an unknown scope, as the service does.
- `tools/assistant-dev/run-question.sh`: mints one token per question, writes `mcp.json` into a fresh
  empty temp directory, and runs `claude -p` with the plan's flags under `env -i`. `PROMPT_FILE`
  overrides the prompt, for controls.
- `tools/assistant-dev/kitchen-assistant.md`: draft system prompt (S3 will move it to `runner/prompts/`).
- `tools/assistant-dev/questions.jsonl`: the 20 questions, each with its expected tool and an English
  gloss for the Kannada ones.
- `tools/assistant-dev/run-eval.py`: runs every question, keeps the raw stream-json, and writes one
  summary row per question. `QUESTIONS_FILE` overrides the question set.
- `tools/assistant-dev/results/2026-10-03-run1.jsonl`, `…-kn-control-no-wordlist.jsonl`: the summary
  rows. Each row has the tools called with their inputs, the full tool result text, the answer,
  timings, tokens and cost. These files contain no token (checked with `grep eyJ`).
- `docs/work/proof/E10-T8.md`: this file.

## The exact command (from `run-question.sh`)

```bash
cd "$WORK"   # mktemp -d, empty except mcp.json
env -i PATH="/usr/bin:/bin:/usr/sbin:/sbin:<dir of claude>" HOME="$HOME" USER="$USER" LANG=en_US.UTF-8 \
  claude -p --restricted --setting-sources "" --disable-slash-commands \
  --system-prompt "$(cat kitchen-assistant.md)" --tools "" --strict-mcp-config \
  --mcp-config "$WORK/mcp.json" --allowedTools "mcp__ikms__*" --permission-mode dontAsk \
  --model sonnet --no-session-persistence --output-format stream-json --verbose \
  --include-partial-messages "<question>"
```

`mcp.json`: `{"mcpServers":{"ikms":{"type":"http","url":"http://localhost:8091/mcp","headers":{"Authorization":"Bearer <token>"}}}}`

The init event of every run listed `tools: ["mcp__ikms__get_inventory","mcp__ikms__list_low_stock"]`,
`mcp_servers: [{"name":"ikms","status":"connected"}]`, `slash_commands: []` and `skills: []`.

## Control: Kannada without the word list

The draft prompt has a short Kannada-to-English list (ತೊಗರಿ ಬೇಳೆ = toor dal, ತುಪ್ಪ = ghee, …), and 5 of the
10 Kannada questions use words from it. To check that the score did not come from that list, I removed the
list and the Kannada and transliterated examples from a copy of the prompt, and reran the 10 Kannada
questions (`PROMPT_FILE=… QUESTIONS_FILE=kn.jsonl`):

```
kn01 … kn10 all ok=True
score 10 / 10
control kn 10 ok 10 dur p50 6.14 p95 8.22 | wall p50 10.16 p95 12.29 max 12.40 | ttft p50 1.45 | cost total 0.1182
```

The tool inputs were identical to run 1 (toor dal, ghee, jaggery, curd, rice + moong dal, coconut). The
wall-clock times are about 4 s higher than CLI time in this run, against about 1 s in run 1. I did not
investigate that. It looks like machine load rather than the prompt, because CLI time moved only about
0.5 s.

## Things found that are worth knowing (not failures)

1. **`get_inventory` with no name returns the first 50 items alphabetically, out of 119 here.** Anything
   after "Curry leaves" is unreachable by "list everything". The tool does say `truncated: true,
   total_matching: 119`. None of the 20 questions needed the full list, so this did not affect the score.
   This is in T6's code. I changed nothing.
2. **The local database has no Kannada glossary** (`translation_glossary` has 0 `kn` rows), so the tool
   returned no Kannada names. Every Kannada item name in the answers is the model's own translation, and
   these vary between runs. Mace came out as ಜಾಯಿಕಾಯಿ ಹೂವು, ಜಾಜಿಪತ್ರೆ and ಜಾಪತ್ರೆ in different runs; ajwain as
   ಅಜವಾನ and ಓಂಕಾಳು. The draft prompt asks for a Kannada name. See "Needs Rajeev".
3. **Cover was `known: false` for every item** in this data, so no "days of cover" claim could be tested.
   The model correctly said it was unknown each time.
4. The init event still lists three built-in plugins (`cc-plugin-agents-md`, `cc-plugin-telemetry`,
   `cc-plugin-plugin-authoring`) and five agent types, even under `--restricted --setting-sources ""`.
   The usable tool list was only the two MCP tools, and no plugin or agent was used. This is for S3's
   lockdown review, not a T8 defect.
5. The data itself has odd figures, and the model flagged one of them unprompted. "Coconut, grated" shows
   107,817.147 Kg, and Groundnut oil shows 81,167 L.

## Acceptance criteria

- **≥ 19/20 correct tool choice, 10 EN + 10 KN:** 20/20 in run 1 (the log above), plus 10/10 in the
  Kannada control.
- Mint per question as `AgentTokenService` does: every run connected to `/mcp` (`status: connected`)
  and got tool results. A wrongly signed token would have been a bare 401 with no tools listed.
- Allow-listed environment: `env -i` with PATH, HOME, USER and LANG only. CLAUDE_CODE_OAUTH_TOKEN is
  passed only if set, and it was not set here.
- Backend stopped. The database copy was dropped and the container left stopped, as found.
