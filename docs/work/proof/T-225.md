# T-225 — below 1024px the sidebar becomes a drawer behind a "Menu" bar; 1024px and up unchanged

**Breakpoint:** Tailwind `lg`, 1024px. Below it (phones, portrait tablets incl. 768): no column, a
56px bar with "Menu" (tabler `ti-menu-2` + the word) and the temple's name; Menu opens the same
sidebar as a drawer from the left over a dimmed page. 1024 and up: the column exactly as before.
This departs from DESIGN_SYSTEM §5 ("collapses ... under 768px") because Rajeev's requirement names
tablet portrait; §5 is a locked document and was not edited (see Not done).

**Files changed:** (no explicit paths list was given with the task; these are the files the task
needed, and none is on the shared-file forbidden list except Sidebar.tsx, which the task directed me
to change)

- `frontend/components/Sidebar.tsx` — the drawer, top bar, focus/escape/scroll-lock/inert logic.
  The nav itself is the same single element (no duplicated nav items). Existing classes on nav items,
  the icon button and the corners were not changed (the T-221 corner note stands).
  `fitToWidth` gained an optional max-size argument; the name-fitting effect moved into a
  `useFittedName` hook so the bar can reuse it and the column's name refits when the drawer opens

**Acceptance criteria:**

- Hidden below lg, bar with temple name + Menu: browser, 390/768/1023 frames: bar 0..width, 56px
  tall; `#app-menu` display none; main left 0, full width; `scrollWidth` == viewport (no sideways
  scroll).
- Drawer from the left with backdrop: browser at 390, clicked Menu: 280px panel at left 0, full
  height, page dimmed behind. Screenshot inspected.
- Closes on backdrop, Escape, Close button: all three done with real clicks/keys at 390; each time
  dialog gone and focus on the Menu button. Also in vitest.
- Closes on navigation: vitest (clicking a link in the drawer closes it and unlocks scroll). Page
  navigation itself also unmounts it, since each page mounts its own sidebar.
- Focus in on open, trapped, returned on close: browser: after open `activeElement` = Close; Tab
  stayed inside (harness has only one focusable); main and bar `inert`. Vitest covers Tab and
  Shift+Tab wrap between Close and Sign out.
- Body scroll locked: browser `body.style.overflow` = hidden while open, restored after.
- aria-expanded/aria-controls, dialog with name: browser read role=dialog, aria-label=Menu,
  aria-modal=true, aria-expanded true/false. Vitest too.
- Reduced motion: the slide is only `motion-safe:`; the global reduced-motion rule also zeroes
  durations. Vitest checks the class. Not emulated in the browser.
- Laptop and up unchanged: browser at 1024, 1280, 1920: bar display none, nav 0..280 sticky, main
  starts at 280, row direction, no sideways scroll.
- Controls use `rounded-control` (Menu, Close).
