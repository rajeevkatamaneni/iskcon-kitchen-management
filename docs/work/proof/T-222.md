# T-222 — layout pass on Today, Meal planner, Recipes and the Vaishnava calendar

Reviewed 2026-09-17 on the local app (next dev, copy of staging data), signed in as Temple Admin,
at 1456px and at 390px. Nothing was saved, updated or cancelled; edit forms were opened and left.

**How phone width was checked.** The Chrome window would not resize (it reports 1470px whatever it
is asked for), so each screen was loaded in a 390px-wide frame inside the tab. Media queries run
against the frame, so the layout is the real phone layout. The main sidebar was hidden inside the
frame to see the content, for the reason in the first item of the decide list.

Skills applied: better-interface, routing to better-layout, better-ui, better-typography,
better-colors and better-accessibility. Wording was not touched (better-writing not applied, by
instruction).

## Shared components (fix every screen at once)

1. **Pages had a 32px gutter on a phone.** `components/ds/Screen.tsx:7` `p-8` → `p-4 sm:p-8`.
   Before: text sat 32px in from each side at 390px, and the date stepper ran into the right edge.
   After: 16px gutter on a phone, unchanged on a laptop.
2. **Page header never wrapped.** `components/ds/PageHeader.tsx:19-25`. The title block could shrink
   to nothing, so on a phone "Friday, 18 September" wrapped word by word into a narrow column while
   "Record a delivery" ran off the screen. Now the row wraps: the title keeps at least 15rem and the
   buttons drop underneath it. Laptop unchanged.
3. **Notices squeezed their own text on a phone.** `components/ds/InlineNotice.tsx:94` `flex-1` →
   `grow basis-60`. The comment above it already said the button drops under the words on a narrow
   screen; it didn't, because the text had a starting width of zero. Before: four or five words a
   line beside the button. After: full-width text with the button underneath. Laptop unchanged.
4. **Field rows ran off the side on a phone.** `components/ds/FieldRow.tsx:43-47`. A row of three
   16rem fields is 48rem, and it never wrapped by design. On the meal form it pushed the page to
   874px wide. Below 640px the row now stacks one field under another; laptop layout untouched.
5. **Badge had no blue tone.** `components/ds/Badge.tsx:35` adds `info` (the Ekadashi pair the
   planner's week and the calendar already use), so the day view could stop drawing Ekadashi amber.
6. **Stat tile notes wrapped with a one-word last line.** `components/ds/StatTile.tsx:46` adds
   `text-pretty`. Before: "…have no known / price". After: "…have no / known price".
