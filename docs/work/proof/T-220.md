## The change, if approved

There are three parts. The first two are central.

1. `components/ds/Badge.tsx:35` changes from

   ```tsx
   shape === "pill" ? "rounded-full" : "rounded-sm",
   ```

   to `"rounded-control"` for both shapes. The `shape` prop becomes meaningless, so either leave it or remove its 4 call sites.

2. In `tailwind.config.ts`, point the fixed steps at the theme's two corners, so every hand-made chip, button, box and notice follows the pack the way `.btn` already does:

   ```ts
   borderRadius: {
     sm: "var(--kms-radius-control)",
     DEFAULT: "var(--kms-radius-control)",
     lg: "var(--kms-radius-card)",
     "2xl": "var(--kms-radius-card)",
     card: "var(--kms-radius-card)",
     control: "var(--kms-radius-control)",
   },
   ```

   This one edit covers about 215 usages, including the Counter, the Readout, the segmented control and the notices. `rounded-full` is not affected, so the circles and meter bars stay round without anyone having to think about it.

3. Eleven `rounded-full` pills get hand-edited to `rounded-control`: planner/page.tsx:349, :357, :546, :554; MealServices.tsx:1203, :1259; MealComposer.tsx:1184; PeriodNav.tsx:97; settings/page.tsx:753, :1313; give/DonatePage.tsx:468.

Estimate: about 1 hour. That is 20 minutes of edits, then tsc, vitest, `next build`, and a look across the planner, meal form, invoices, settings and sign-in. No test asserts a radius class (grep of `__tests__` for `rounded-` finds nothing), so no tests should need changing.
