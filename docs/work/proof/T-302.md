## The rule, as T-299 set it

The second amount goes only when it repeats the pack: one pack with no name. "No name" means the label has no " (" in it, which is how `packWord` in `RecordDeliveryPanel.tsx` tells them apart. "One" is counted in packs (rounded to 3 places, as displayed), not found by comparing text. So a "0.5 Kg" label over a "500 gm" total counts as a repeat too. "2 × 500 gm" keeps "1 Kg". "1 × Bag (25 Kg)" keeps "25 Kg".

T-299's `repeatsPack` is not exported, and `RecordDeliveryPanel.tsx` is outside my list. So each of the three components has the same one-line test inline, with a comment pointing back to T-299. If someone later exports a shared helper, these three lines can use it.
