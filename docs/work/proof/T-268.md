## What was built

`SheetRupees.format(BigDecimal)`: round to paise half-up, then "₹" + Indian grouping + ".pp" only when the paise are not 00. Same rule as `frontend/lib/format.ts money()`.

**Found on the way: Java cannot group lakhs.** My first version used `NumberFormat` for en-IN, the same as `donation/Rupees.java`. The unit test failed: `expected: "₹1,00,000" but was: "₹100,000"` (output below). `DecimalFormat` keeps one grouping size, so the CLDR pattern `#,##,##0` becomes groups of three. So the grouping is done by hand (last three digits, then pairs).

**Why a copy and not the donations `Rupees`:** it is package-private in `donation` (making it shared means editing a file outside this contract), and it has the lakh bug above.

## Which documents use this formatter

`money()` is `private` to `DocumentGenerationService`, and its only callers are the PO sheet's line rate, pack price and total (in `buildSheetModel`). The recipe card, job card and work order print no money at all (checked by grep for price/cost/₹ in their templates and services). The donation receipt gets its amount already formatted by `donation/Rupees.format`. So only the PO sheet changes. The PDF and the print view both call `PurchaseOrderSheetTemplate.render(buildSheetModel(...))` (lines 121 and 175), so they change together.

- ₹1,00,000 grouping: unit test (`₹1,00,000`, `₹12,34,567`, `₹1,23,45,678.50`), and the sheet total `>₹1,01,535.60<` in `PurchaseOrderDocumentIT`.

- ₹0.07 per gm stays readable: `>₹0.07 / gm<` on a 500 gm line at ₹0.0712 in `PurchaseOrderDocumentIT`.
- Pack line "₹1,500 / bag · ₹60 / Kg": `PurchaseOrderPackLineIT`, plus `>₹200 / 500 gm · ₹400 / Kg<` and total `>₹6,598.79<`.
- Real PDF text: checked by hand as described above, not inside the suite.
- Other documents: none use this formatter (see above). JobCardIT, DocumentGenerationIT and DonationReceiptTemplateTest were run and are green.
- Kannada: `PurchaseOrderTranslationIT` prints the same PO in `kn` and `en`. Both contain `>₹1,500 / Kg<` and `>₹45,000<`, and the Kannada one has no `[kn] ₹`.
