**What was done**
- D-6. Cause: the global `h1 { @apply text-2xl }` in `globals.css` carries `letter-spacing: -0.02em`. FocusScreen's `sm:text-xl`/`text-lg` only set size and line height, so the h1 kept -0.02em × 22px = -0.44px. The mock uses a `<p>` with the same classes and no tracking. Fix, in the page only: `task={<span className="tracking-normal">Create a purchase order</span>}`, with a comment giving the reason. The heading stays an h1, and its accessible name is unchanged. FocusScreen was left alone because it is a shared component and every other form screen uses it.
- D-7. The mock has no no-vendor state for the create form. Its only similar text is "Choose a vendor to see what they sell." in the catalogue designs, which is a different case. So the sentence "No vendor is active yet. Add a vendor, then come back…" and its comment were removed, along with the `next/link` import that only it used. No test asserted the sentence.
