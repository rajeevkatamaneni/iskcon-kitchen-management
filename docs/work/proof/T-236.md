## Browser measurements (local dev, signed in, Chrome; same-origin iframe at a fixed width)

Method: for each column, the leftmost and rightmost content edge over every row (text line boxes,
inputs, buttons, badges' boxes); gap = next column's left edge minus this column's right edge.
Clipping = any cell or number box with `scrollWidth > clientWidth`. Wrap = a text node whose line
boxes sit on more than one line. The "before" pass counted badge text but not badge padding, so a
column ending in a badge read up to 8px wider in the before numbers; the after pass counts the badge.
