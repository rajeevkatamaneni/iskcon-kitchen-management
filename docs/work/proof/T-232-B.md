# T-232 part B — screen sweep: ordering, money, giving, settings, messages

Local `next dev`, signed in as the Temple Admin. Every width below was checked by loading the screen
in a same-origin iframe of that exact width (390, 768, 1280, 1920) and measuring the DOM with
`getBoundingClientRect` / `getComputedStyle`. Nothing below is eyeballed: where a figure is given it
was measured; where something was not measured it says "not verified".

Measured on every screen at every width: page `scrollWidth` against the viewport (sideways scroll),
any element whose right edge passes the viewport, boxes that scroll sideways inside themselves, form
controls narrower than 90px, text cut off with an ellipsis, and buttons/checkbox labels under the
44px touch height. At 1920 every screen measured `scrollWidth = 1920` with nothing past the edge.

Drawer menu below 1024px (shared Sidebar, not changed here): on /settings at 390 the Menu button sets
`aria-expanded=true` and, once its open animation finishes, the drawer is 280px wide with its links
starting 16px from the left edge. (The tab was hidden, which pauses animations, so the animation was
finished by script before measuring.)
