# T-156 — a ds `Button` no longer submits its form unless it says `type="submit"`

**Files changed** (all inside the contract):

- `frontend/components/ds/Button.tsx`: the default.
- `frontend/__tests__/button-type.test.tsx`: new.
- `docs/work/proof/T-156.md`: this file.

No caller was changed, because the sweep found no caller that relied on the implicit submit (see
below). No existing test was changed.

## The default and where it sits

`type = "button"` is destructured out of the props next to `busy` and `disabled`, and written as
`type={type}` **after** `{...rest}`. I did not put `type="button"` ahead of the spread, because a
wrapper that forwards an optional `type` as `type={undefined}` would spread over it and bring back
the browser's submit. A destructuring default covers `undefined` as well, and one test proves it.
There is a comment in the file saying why.

## Acceptance criteria

- Button in a form with an `onSubmit` spy does not submit. `type="submit"` does. An explicit type
  wins, shown with `type="reset"` firing `onReset` and not `onSubmit`. Proved by
  `button-type.test.tsx`, and control A shows the default is what makes it pass.
- Real click, not `fireEvent.submit`: **deviation.** `@testing-library/user-event` is not installed,
  and adding it would change `package.json`, which is outside the contract. The test uses
  `fireEvent.click`. That dispatches a click on the button, and jsdom's own button activation decides
  whether the form submits, so the test never calls submit itself.
- Enter in a text box: **cannot be pressed in jsdom**, which does not implement implicit submission.
  The test asserts the thing a browser uses on Enter, which is that the form's default button (the
  first submit-type control) is the save button and not an earlier "remove". Under the old code it
  was the remove button, and control A shows that. No form's submit changed in this sweep, so no
  per-form Enter test was owed.
- A form left with no submit button: none found. All 21 forms with no internal submit are
  accounted for above.
- Both negative controls: red, and the restores were proved with `cmp`, above.
- tsc, full vitest and eslint: see Final.
