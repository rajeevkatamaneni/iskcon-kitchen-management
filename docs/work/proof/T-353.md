- This proof.

Why RequireRole reads `window.location` and not `usePathname()`: 105 test files mock `next/navigation` without `usePathname`, and a factory mock throws on a missing export. Reading the path during render would also be wrong on a client-side navigation, because Next writes the new URL in an insertion effect. So the path is read in a layout effect, and only a person with `canPlanMeals === false` waits one commit for it (before paint, without mounting the page).
