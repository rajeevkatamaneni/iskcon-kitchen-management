# T-241 — throwaway mock of three ways to lay out a two-column table, on the Basmati Ghee Rice page

**Files changed:** one new file, `frontend/app/dev-two-col/page.tsx` (inside the contract). Its top
comment says "THROWAWAY MOCK for T-241 — delete before any deploy". No existing component, token,
page or stylesheet was touched. `app/globals.css`, `components/ds/Button.tsx` and `app/dev-buttons`

**What the page is:** the recipe page drawn three times, one under the other, each headed
"Option n — …". It uses the real sidebar, `Screen`, the real header, facts row, Ingredients line
(language picker and download icon, static) and method, and the real table constants
(`RULED_TABLE`, `TH_PRIMARY`, `TD_FIXED_NUM` …) so the shared table fitter spaces it exactly as it
spaces the real page. Figures read from the local database for Basmati Ghee Rice: 17 ingredients in
line order, Makes 100 L, Per person 350 ml, ₹8,000 per batch (100 L), method (3 steps), note and
vessel. No API call and no role check.

The only differences between the three:
- Option 1, narrow: box `w-fit`, table `!w-auto`, first column `!pr-[68px] !whitespace-nowrap`
  (68 + Quantity's own 12px padding = 80px gap).
- Option 2, right edge: Quantity heading and cells `!text-right`.
- Option 3, as built: unchanged.
