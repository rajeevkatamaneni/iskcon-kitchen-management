## What was built

- **Supplies table.** Columns are Ingredient · Sells it as · List price · Lead time · Preferred · actions. "Last price" is now "List price", and "Edit a row to change any of the three." is gone. List price reads "₹1,500 / bag · ₹60 / Kg" for a pack supply, or "₹60 / Kg" for a loose one. The PriceTrend marker sits beside it. Edit → Save/Cancel works as it did, with the same four facts as the new table. Supplies sold in a pack open with the price per pack in the box. When there are no supplies, it says "Nothing from this vendor yet. Tick what they sell under Other ingredients."
- **Other ingredients.** Lists every ingredient this vendor doesn't supply. Each row has a tick with the name as its label, Sells it as, List price (₹), Lead time (days) (with the existing hint on an "i" in the heading) and Preferred. It has a Search box and a Category filter, with Save and "N ticked" on the same row. Save sends every ticked row in one `addVendorSupplies` call, including ticked rows the filter is hiding. A green notice then reads "3 ingredients added to Supplies." The rows are a `Form`, so a lead time over 365 is named beside its box.
- **Payload rule.** With a pack: `pricePerPack` = typed price, `packSizeId` = the pack, `lastPrice` = null (the server refuses a per-unit price beside a pack, KMS-400163). Without a pack: `lastPrice` = typed price, and both pack fields are null. All six keys are always sent. The same function builds both the edit row's payload and the bulk payload.
- **Add a pack size…** is the last option in Sells it as, in both tables. It opens a row under the ingredient with Pack name (optional), Size, and Unit (same family only, e.g. Kg/gm). It saves with `addPackSize`, reloads the ingredients and selects the new pack. Server refusals show inside that row. A blank or 0 size is stopped before any call ("Size must be more than 0").
- **PriceTrend.** Red `ti-arrow-up` when the price rose, green `ti-arrow-down` when it fell, a neutral `ti-minus` when unchanged, and nothing when there is no previous price. It takes keyboard focus. Hover, focus or tap shows "₹60 on 12 Sept" (`shortDate`). Its spoken name says the direction in words ("Up from ₹60 on 12 Sept"). It is drawn at 24px, with a 44px touch area from a `before:` layer.
- **Tooltip fix (R-INV-5).** When it opens, the tip is measured before paint:
  - its width is capped at `min(20rem, 100vw − 16px)`
  - it slides sideways to stay 8px inside the window
  - it opens above its control when there is no room below
  - it refits on window resize
  - it no longer inherits a table heading's uppercase
  - InfoHint needed no change. Its tests, and every test file that uses it, pass (run 4).

## Calls I made, recorded

1. **Conductor's rulings (2026-09-19), built as given:**
   - the one-at-a-time "Add supply" form is removed
   - supplies keep the per-row Edit → Save/Cancel
   - "Add a pack size…" is the last option in Sells it as, with inline fields, saved with addPackSize and then selected
2. **Prices kept per gm or per ml are shown per Kg or per L** ("₹68 / Kg", not "₹0.07 / gm"), using the existing `convertQuantity`. At 2 decimals, ₹0.065 and ₹0.068 per gm both print "₹0.07", which would put a red arrow beside two identical figures. The tooltip's previous price uses the same unit.
3. **Typing into an Other ingredients row, or choosing its pack, ticks it.** Only the tick box unticks. Without this, a price typed into an unticked row would be dropped on Save with no warning. The spec doesn't say this; Rajeev can overrule it on the Desk.
4. **The tooltip's previous price has no unit**, exactly as the spec words it: "₹60 on 12 Sept". The marker sits right after the per-unit figure, so that is the figure it refers to.
5. **The first load alone shows "Loading vendor…".** A reload after a save keeps the page on screen, so a 200-row list doesn't blank out and lose its scroll position.
6. **Other ingredients uses the mocks' entry-grid pattern** (`TABLE` + `ENTRY_GRID`, `data-label` on each cell for the phone card). Only the Ingredient column may wrap when the table is short of room. The per-Kg figure worked out while typing ("= ₹60 / Kg") sits on its own line under the price box, to keep that column narrow.
7. **Preferred behaves as it does today.** The server moves the preference, and the existing sentence above the tables still says so. "Replaces A" (R-VEN-2) is not built.
