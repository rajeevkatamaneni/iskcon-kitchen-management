**Judgement calls:**

1. **Kept `/orders/new/lines` as a redirect, not deleted.** It is a server component calling `redirect()`, and it keeps `?vendor=`. `/orders/new` preselects that vendor only if it is active.
2. **Number boxes use `min-w-28`, where the mock has `w-28`.** The table rule (DESIGN_SYSTEM §5, and the `table-rule.test.ts` check "gives no number box in a table a fixed width") forbids a fixed width. Following the document's rule, not the mock. The measured width is still 112px.
3. **The one-off text is built as a JS string with literal ‘ ’ characters**, because `design-system.test.ts` forbids HTML entities such as `&lsquo;`.
4. **Line totals, order total and the per-Kg list price are rounded to paise.** Checked in node: 0.07 × 300 = 21.000000000000004, which `money()` would print as "₹21.00". Tested.
5. **List price in the dropdown** is `lastPrice` said per Kg or L for gm/ml prices, the vendor page's rule, using the shared `convertQuantity`. Counts use `unitLabelFor(1, …)`, so it reads "₹4/piece", not "/pieces" as the mock's `unitLabel` gives. Pack prices ("₹1,500 / bag") are not shown. The brief said to show the list price per readable unit only.
6. **Picking fills Unit with the ingredient's own unit and Expected price with the raw `lastPrice`**, so a gm line gets 0.068. This is what `expected_price × quantity` means on the server.
7. **Order within each group is alphabetical.** The mock uses its data order. Matching is on the name only, as in the mock; aliases are not searched.
8. **Changing vendor after adding lines leaves those lines' prices alone.** The document is silent on this.
9. **Validation:** quantity boxes are `required` with `data-more-than="0"`, so `Form` names "Quantity of X is required" beside the box. An order with no items gets "An order needs at least one item. Type one into the Items table." This is page text; no new error code was needed because nothing reached the server.
10. **No active vendors:** a line under the header says "No vendor is active yet. Add a vendor, then come back to create the order." with a link. The old step one's "Add a vendor" button went with that screen, and this is the only way out for that case. It is not in the mock.
11. **Wording changes on the list page to match "Create":** the subtitle says "create a one-off by hand" and the confirmation says "was created". Neither is named in the document.
12. **`data-testid="order-total"`** on the total figure, used by the tests only.
