## The composer finding

Its `onSubmit` still only calls `preventDefault`, and every action is a header button outside the form.
`Button` defaults to `type="button"`, so none of them submits. The one way to submit is Enter in Subject, the
form's only text box when the channel is Email, which submits it implicitly. jsdom has no implicit
submission, so the tests fire the submit event that Enter would.

- Blank subject + Enter: before, the browser's grey bubble. **Now `Subject is required` in red beside the box.** Nothing is saved in either case. This is the only visible change.
- Subject filled + Enter: nothing happens, as before.
- **Found, not changed:** "Save and preview" is not disabled and not a submit, so `Form` never sees it. It saves a draft with a **blank subject**, and no sentence shows. The test pins this as today's behaviour.
