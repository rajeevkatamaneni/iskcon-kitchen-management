## What was built

- **N1.** As T-292 did on the vendor page: the server's refusal is cleared on any change to Pack name, Size or Unit, and at the start of every Add pack size press, before the "Size must be more than 0" check. A successful add clears it by the same press. The -5 case: the shared `Form` refuses -5 itself (the box has `min="0"`), so `add()` never runs; typing the -5 is what clears the old refusal now.
- **N2, as ruled by the conductor on 2026-09-19.** The task first asked for the unit in the tip ("₹1,500 / bag · ₹60 / Kg on …"). The clarifier pointed out R-VEN-3's acceptance check fixes the words as "₹60 on <date>", and the conductor ruled: keep "₹<amount> on <date>", but give the amount in the unit the row leads with. So a bag supply's tip is the old price per bag (old per-Kg × today's bag), "₹1,500 on 19 Sept"; a supply sold by the Kg keeps "₹60 on 19 Sept" (a gram price said per Kg, as before). One helper, `previousPriceText(supply, packs)`, is passed as PriceTrend's `format` on both pages. The amount is rounded to paise. If the pack isn't loaded, it falls back to the per-Kg figure. `readableRate`/`readablePackRate` are not used after the ruling, because they add unit words.
- **N3.** The Preferred cell has `data-label="Preferred"` when it is the dash, and none when it is the badge, the same as the vendor page.
- **N4.** The tick and the Link vendor button are now one item, the last in the same wrapping row as the four boxes, with `self-end` so they sit level with the boxes. Each thing moves to a new row only when it can't fit.

**My edge-width decision (Q-18 logic).** Nothing reserves space for the longest "Preferred (replaces …)" label. Where the pair fits beside Lead time only while the label says plain "Preferred", ticking it for an ingredient another vendor holds can move the pair to its own row. I didn't reserve the width because that would leave a blank block every time the tick isn't in that state. The pair itself never splits into two rows except on a phone, where the words wrap inside it as before. At 1024 with the longest real label in the data ("Preferred (replaces VERIFY2-A Vendor Two)", 252px) the pair still fits on row 2 (measured below).
