## What was built

- **A2.** In `PackSizeRow`, a server refusal is cleared the moment Pack name, Size or Unit changes, and at the start of every Add pack size press, before the "Size must be more than 0" check. Before this, it was cleared only after that check passed.
- **A7.** The cause is shared. Below 1024px, `.kms-table > thead` and `.kms-entry-grid > thead` are hidden sr-only style (globals.css): 1px, clipped. That is fine for text but wrong for a button, which still takes Tab. I did not change globals.css (outside the contract). The fix is in `InfoHint`: when the "i" sits inside one of those headings and `matchMedia("(min-width: 1024px)")` is false, it is not rendered. That takes it out of the tab order and the accessibility tree together, and it comes back when the window widens. An "i" anywhere else is untouched. It is script, not a Tailwind class, so jsdom can test it; a class can only be checked in a real browser. The component now wraps itself in a `display: contents` span, which the hook needs to look up from. Measured with and without it, the heading geometry is identical (below).
- **The hint on phones** (conductor's ruling 2026-09-19, option 2 of 3, via the clarifier): one `lg:hidden` line, "Lead time (days)" with the same `InfoHint` and the same text, above the Other ingredients cards. It is one Tab stop, not one per card (~200 on a real list). My layout call: it sits 24px under the filters and 16px over the first card's text, so it groups with the cards. With the table's usual 16px margin it measured 16px under the filters and 33px over the cards, and read as part of the filter row. So the table margin is `max-lg:mt-0`, and desktop keeps `mt-4`.
- **A8.** The Supplies Preferred cell has `data-label="Preferred"` when its value is the dash. When it is the Preferred badge it has no label, since "Preferred Preferred" would be worse (§5 lesser evil). `data-label` prints only on the card, so the wide table is unchanged.
- **A1.** Re-measured. There was nothing left to fix in this page (numbers below).

Grep of every `<thead>` in `app/` and `components/`: this Lead time "i" is the only focusable control inside any table heading in the app. No other page changes behaviour.
