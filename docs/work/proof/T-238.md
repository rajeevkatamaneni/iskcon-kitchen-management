**What the page shows:** http://localhost:3000/dev-buttons (local `next dev`). A theme-pack picker at the top (default: whatever this browser is wearing; all 15 packs selectable, applied to the page's own wrapper only). A summary table of measured contrast. Then eight styles, each with a rest / hover / keyboard-focus strip and the same button in three contexts: (1) beside the primary "Update this meal", (2) a copy of the meal edit "Who will run it" row with the grey People needed counter and the amber Rostered box, (3) on a white card beside a text input.

Finding worth knowing first: the "Ask for volunteers" button is `<Button variant="secondary">`, which is the `.btn-quiet` material (accent text, pale accent hairline, no fill), not `.btn-secondary`. The app's neutral second button is `variant="ghost"` = `.btn-secondary`. Both are shown as today's looks.

The styles:
- A1 — today, as on "Ask for volunteers": accent text, pale accent hairline, no fill.
- A2 — today, the neutral second button (`ghost`): white fill, thin grey hairline, grey text.
- B — 1.5px border in `--ink-secondary`, `--ink` text, white fill. Hover: sunken fill, ink border.
- C — `--hairline` fill, no border, `--ink` text. Hover: `--hairline-strong` fill.
- D — 1.5px `--accent` border, `--accent-text`, white fill. Hover: `--accent-bg` fill.
- E — 1px `--ink-muted` border with a 2px `--ink-secondary` bottom edge and a small shadow. Hover: sunken fill, bigger shadow. (Its shadow uses `rgb(var(--kms-ink) / 0.14)`, the one alpha on the page.)
- F — `--hairline-strong` fill, no border, `--ink` text. Hover: `--ink-muted` border appears.
- G — `--accent-bg` fill, 1px `--accent` border, `--accent-text`. Hover: `--accent-border` fill.

All use `.btn` (pack's `--radius-control`), the same base classes as `BUTTON_CLASSES`, and the global focus ring.
