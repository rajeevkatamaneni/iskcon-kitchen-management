# T-311 — WhatsApp PO dates write "Sept" like the screens and the sheet; Today's cost tile names list prices and the market rate

**Files changed** (all inside the contract: the purchaseorder delivery service and its test, the Today page and its test):

- `backend/src/main/java/org/iskcon/kms/purchaseorder/PurchaseOrderDeliveryService.java`: the `WHEN` formatter is now `ofPattern("d MMM yyyy", java.util.Locale.UK)`. It is the only formatter in the file and feeds only the `raised` and `neededBy` parameters of `po_delivery`. The Meta template text is unchanged.
- `backend/src/test/java/org/iskcon/kms/purchaseorder/PurchaseOrderWhatsAppIT.java`: new test `theWhatsAppDatesMatchTheScreen`.
- `frontend/app/today/page.tsx`: `materialsNote` now returns "Estimated from list prices, or the market rate".
- `frontend/__tests__/today.test.tsx`: asserts the new line and that "last-known" is gone.

I did not touch the planner, the meal package, the document package, api.ts, RolePermissions or ErrorCode.

## Why it was done this way

1. **Dates.** T-310's fix is the private constant `DATE` in `document/DocumentGenerationService.java`. It is private and in a package outside my paths, so I could not call it. I used the same pattern and the same locale, and the comment says the two constants should become one shared constant if they ever need to change together. `DocumentGenerationService` has no public date helper, and `lib/format.ts` is frontend.
2. **Tile wording** (ux-writing skill). Cost per serving (T-310) reads "Estimated, materials only — from list prices, or the market rate". The tile uses the same words and drops "materials only", because the tile's title is already "Cost of materials". The "n ingredients have no known price" variant is unchanged, as it was on Cost per serving.
