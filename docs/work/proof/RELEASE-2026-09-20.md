## Why it is two code commits and not three

T-401 and T-403 edit the same five classes in `backend/.../library/` and the same fixture book, so
they cannot be separated by file without splitting hunks inside a single method. T-403 also needs
T-402's column to exist. The split that is real is **the flag** and **the library path that feeds
it**, and that is what the two commits are. `frontend/lib/api.ts` carries all three tasks' type
additions; its four hunks divide cleanly — `MasterRecipeIngredient` to the library commit, the
`IngredientView`/`CreateIngredientInput`/client-method hunks to the flag commit — so each commit
holds a tree that declares the types the rest of that commit uses.
