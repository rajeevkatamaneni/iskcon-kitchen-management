Design choices worth knowing:
- The prompt goes to `claude` on **stdin**, not as the last argument as run-question.sh does. An argument starting with "-" would be read as a flag, and a long history could hit the argument-size limit. The real smoke run below shows stdin works with these flags.
- Child env is built from nothing: PATH (system dirs + the CLI's dir), LANG, HOME, and one credential. With a credential set, HOME is a fresh empty dir per run (inside the run's temp dir), not the runner's home. With no credential (stored-login mode, Mac only) HOME and **USER** are the real ones, because run-question.sh/T8 found the keychain login needs USER too. That is one variable more than the task's list, only in local mode.
- Errors before a run (400 unknown_profile / invalid_request, 413, 503 busy with Retry-After: 2) are plain JSON in the same `{type:"runner_error",code,message}` shape. Once the run starts the status is 200 and failures are the last NDJSON line: `timeout`, `spawn_failed`, `exit_nonzero` (with exitCode).
- If the caller disconnects mid-run, the process is killed.
- Logged per run: runId, profile, prompt length, mcpUrl, result, exit code, ms, line count. Child stderr is logged only on failure, with the token and credential redacted.

**Acceptance criteria:**

- POST /run with the four fields spawns `claude -p` with the §2 flags: unit test on argv + the real run above.
- Fresh empty temp dir per run, deleted afterwards: e2e test (dir holds only mcp.json; gone after) + 0 leftovers after the real run.
- Allow-listed env, credential precedence: unit tests on buildChildEnv/pickCredential, and the fake `claude` reports its actual env keys = ANTHROPIC_API_KEY, HOME, LANG, PATH.
- mcp.json with Bearer token: e2e test compares the file the fake read.
- Streams NDJSON as it arrives: test shows line 1 reached the client ~800 ms before line 3; real run shows events arriving over 4.2 s.
- 60 s kill (configurable) with runner_error timeout: test at 1 s, fake process confirmed dead. Also spawn_failed and exit_nonzero tested.
- Token and credential never logged: test greps every log entry for token, credential and prompt text; real run grep = 0.
- GET /health, unknown profile rejected, concurrency limit with busy: tested.
- Dockerfile: Node 22 slim, non-root, empty home, image built and served /health.
